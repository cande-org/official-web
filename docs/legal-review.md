# 법률 문서 작성·운영 확인 기록

작성일: 2026-09-19. 시행일: **2026-10-01** (사용자 지정).
담당부서: **Cande 개인정보 보호 담당** (사용자가 명칭 작성을 위임).
연락처: 홈페이지 푸터의 사용자 제공 이메일.

## 작성 범위

- `privacy.html`: 회사 홈페이지와 정병발사 앱의 개인정보처리방침.
- `terms.html`: 정병발사 서비스 이용약관.
- 두 문서 모두 한국어/영문 전체 본문, 목차, 공통 푸터와 교차 링크 제공.
- 일반 문의는 완료 후 파기, 거래 관련 법정기록에만 법정기간 적용.
- 앱 내 기존 간략 안내(`app/lib/features/purchases/legal_document_page.dart`)는
  이번 홈페이지 작업에서 바꾸지 않음. 정식 시행 전 동기화해야 함.
- 정책 작성과 법적 준수 인증은 다름. 아직 확인하지 못한 국외처리 사실은
  이용자에게 보이는 방침에도 ‘시행 전 확인’으로 명확히 표시함.

## 확인한 구현

- Supabase OAuth 인증, 서울 리전 문서, 사용자별 Postgres 데이터와 private Storage.
- OpenAI Chat Completions로 현재 입력·최근 대화·AI 친구 식별자/설정 전송.
  `store:false`; 이를 무보관이나 ZDR로 해석하지 않음.
- RevenueCat 식별자·구매 검증과 스토어 구독. 무료 하루 10회,
  한국 자정 초기화, 무료 우선, 실패/안전 안내 차감 환급.
- 홈페이지 자체 수집폼/광고/분석 없음. 로컬 언어 선택값 저장.

## 시행 전에 운영에서 맞춰야 할 실제 항목

1. OpenAI 계약 법인·실제 처리 국가·data-sharing 설정, Supabase 해외 지원 및
   재위탁 범위, RevenueCat 삭제/백업 SLA, Gmail 국제 처리 조건을 확인하고
   개인정보처리방침 5항의 미확정 표시를 실제 내역으로 대체해야 함.
   홈페이지 호스팅 업체·로그 보존도 배포 환경 결정 후 반영.
2. 일반 문의 완료 후 파기 절차와 법정 거래·분쟁 기록의 분리 보관을 운영에 적용.
   운영 로그/백업에 무작정 3년·5년을 적용하지 말고 목적별 기간을 확정.
3. 계정 삭제 접수 및 검증·처리 담당 지정. 현재 앱에 계정 삭제 UI/전용
   엔드포인트를 확인하지 못했으므로 이메일 요청 경로로 문서화.
   삭제 시 auth/DB/Storage/RevenueCat/캐시/백업을 함께 검토해야 함.
   `mb_entities` 대화방 삭제만으로 `mb_turns`의 입력·결과까지 파기된다고
   보장할 수 없으므로 실제 삭제 절차 검증 필요.
4. 법정 보존 대상 구매 기록은 계정 삭제 CASCADE와 구분하여 관리해야 함.
   현행 스키마에 CASCADE가 있으므로 법정 보존을 코드가 구현했다고 주장하지 않음.
5. 만 14세 미만 이용 제한과 미성년자 결제 동의·약관 동의 절차를
   실제 가입/구매 흐름에 적용. 정책 작성만으로 해당 UI가 구현되지 않음.
6. 법령상 보호책임자 지정 요건 검토와 내부 담당자 지정은 별도로 필요.
   공개 문서에는 요청받은 부서명·연락창구를 표시함.

위 항목을 확인하기 전 개인정보처리방침을 확정된 운영 현황으로 소개하거나
이 초안만으로 스토어/법률 심사 준비가 완료됐다고 주장하지 말 것.
