# 홈페이지 검증: 2026-09-19 개편

- 로컬 Chromium 실렌더에서 한국어/영어 각각 360, 390, 430, 768, 800,
  801, 1024, 1440px 폭 확인: 가로 넘침/텍스트 잘림 없음, 이미지 로딩 성공,
  번역 누락 없음. 800/801px 반응형 경계 포함.
- 저장된 언어가 없는 상태의 한국어 기본값, KO/EN 전환, 새로고침 후 영어
  선택 유지 확인. 제목과 설명도 해당 언어로 변경.
- 내부 앵커 유효성 확인. 별도 문의·가치관·슬로건 섹션 없음.
- 메일 링크는 문서 전체에 정확히 하나, footer 내부에 위치. 실제 발송 없음.
- 일반 모션 설정: 모바일에서 대화 예시는 스크롤 전 숨김, 진입 후 등장 및
  마지막 대화 opacity=1 확인. 나머지 본문에는 숨김/등장 효과 없음.
- reduced-motion 설정: 대화 transition=0s, opacity=1 확인.
- 브라우저 런타임 오류 없음. `npm run check`, `npm run build` 통과.
- 실기기 Safari/Android 검증은 수행하지 않음. 브라우저 뷰포트 검증임.
- 캡처는 전체 내용을 보여주기 위해 reduced-motion 설정에서 촬영.

최종 한국어 화면: [데스크톱](desktop-ko.png), [모바일](mobile-ko.png).
참고 사이트와 개편 판단: [디자인 기록](design-review.md).

## 법률 문서 추가

- 배포 빌드에서 홈페이지 → 개인정보처리방침 푸터 링크 실제 이동 확인.
- `index.html`, `privacy.html`, `terms.html` 각각 KO/EN × 360/768/1440px:
  페이지 가로 넘침·번역 누락 없음. 푸터 법률 링크 2개, 회사 메일 1개.
- 두 법률 문서는 선택 언어의 본문 하나만 노출. 페이지 간 언어 유지,
  목차 이동 및 언어 전환 시 목차 앵커 대응 확인.
- 모바일 표는 자체 가로 스크롤 영역을 사용하며 문서 전체가 넘치지 않음.
- 브라우저 런타임 오류 없음. 별도 법률 문서 파일 및 CSS가 dist에 포함됨.
- [개인정보처리방침 모바일](privacy-mobile.png), [약관 모바일](terms-mobile.png).
- 문구의 운영상 미확정 항목은 [별도 기록](legal-review.md)과 공개 방침에 명시.
