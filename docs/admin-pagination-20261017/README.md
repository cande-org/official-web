# 숫자 페이지 이동과 수정된 친구 — 2026-10-17

모든 관리자 목록의 페이지 컨트롤을 `admin/pagination.js`로 통일했다. 숫자 5개 창·처음/마지막·말줄임, 현재 페이지, 이전/다음, 페이지 번호 입력·Enter/이동을 제공한다. 잘못된 입력은 요청하지 않고 안내하며 검색/필터/페이지 크기를 바꾸면 1페이지로 돌아간다. 모바일에서는 컨트롤을 줄바꿈하고 입력·버튼 높이를 맞춘다.

친구는 이름·사진을 수정한 기본 친구 또는 직접 추가한 친구만 표시한다. DB의 현재 성향이나 수정 시각으로 이름/사진 변경을 추측하지 않는다.

상품·FAQ·약관·관리자 목록, 회원·문의, 공지·푸시, 채팅·결제·광고·친구, 관리자 변경 이력 및 대시보드 기록에 적용한다. 설정 폼·차트·고정 요약은 그대로다. 서버 목록은 정확한 전체 건수와 원하는 페이지를 한 번에 읽으며 공지/푸시/권한 변경 이력의 기존 최근 건수 제한도 제거한다. 목록 전체를 브라우저로 다운로드하지 않는다.

## 확인

문법·단위 23개·브라우저 10개 묶음·빌드 통과. 브라우저 fixture는 미방문 6페이지를 한 요청으로 이동, 마지막 페이지, 0/소수/범위 밖 입력 차단, FAQ 50개, 메뉴별 연결, 사진/권한/로그인 복귀 및 360/390/430px를 확인한다. 캡처에는 합성 데이터만 사용한다.
