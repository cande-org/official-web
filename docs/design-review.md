# Cande 홈페이지 구조 개편

2026-09-19. 사용자 요청: AI처럼 느껴지는 흐름과 카피를 개선하고,
별도 문의 섹션을 삭제. 이메일은 푸터에만 표시.

## 참고한 페이지

- [Panic](https://panic.com/): 회사가 하는 일을 구체적인 제품군으로 설명.
  회사 소개를 짧게 쓰고 제품을 주인공으로 배치하는 점을 참고.
- [teenage engineering / products](https://teenage.engineering/products):
  큰 제품 이미지와 간결한 제품명 중심의 구성. 실브라우저로 확인.
- [Nothing / about](https://nothing.tech/about): 첫 문장에서 만드는 제품을
  구체적으로 밝히는 점을 참고. 장문의 비전·성과 구조는 적용하지 않음.

외부 브랜드의 폰트·이미지·코드를 복사하지 않음. 앱 원본 에셋만 재사용.

## 이전 구성 진단

코드와 변경 전 브라우저 렌더 기준.

| 우선순위 | 위치 | 문제 | 처리 |
| --- | --- | --- | --- |
| P1 | hero/about/statement | ‘작은 내 편’, ‘작은 순간의 힘’, ‘더 가까이’가 제품 설명 전에 반복 | 회사의 실제 작업을 두 문장으로 설명 |
| P1 | contact | 별도 문의 배너와 대형 화살표가 단순 메일 링크를 과장 | 섹션 삭제, 푸터 메일 하나만 유지 |
| P1 | 전체 구조 | 회사 소개/가치관/선언/문의로 페이지가 늘어남 | 회사 → 제품 → 푸터로 통합 |
| P2 | section-label/values | 반복되는 번호·영문 표제·3분할 가치관 | 삭제 |
| P2 | hero-art/reveal | 궤도·별·회전·부유·전체 등장 효과가 겹침 | 장식 제거, 대화 예시에만 제한된 모션 |

## 선택한 방향

제품 카탈로그에 가까운 명확한 구성.

- 회사명은 큰 고딕 워드마크, 제품 영역은 기존 앱 손글씨.
- 흰 바탕과 검은 글자, 제품 시연 영역만 회색 바탕.
- 첫 화면에서 회사와 제품의 관계가 드러나는 짧은 구성.
- 기능은 대화 예시와 두 줄의 설정 정보로 설명.
- 제품 시연에만 한 번의 등장·대화 순차 표시. 본문은 숨기지 않음.

선택하지 않은 방향: 기존 감성 페이지의 문구만 교체하기, 사진 중심의
브랜드 소개를 새로 만들기. 전자는 반복 구조를 유지하고 후자는 회사의 실제
자료가 없는 상태에서 장식을 늘리므로 현재 요청에 맞지 않음.

## 재검토

- 선언형 슬로건, 과장 수식어, 임의 지표/후기/출시 상태 없음.
- 제목과 내용에 직접 설명되지 않는 CTA 없음.
- 연락처는 푸터에 한 번. 한국어·영어 모두 같은 구조.
- 실제 앱 에셋과 구체적인 앱 기능으로 구성.
- 손글씨와 캐릭터는 제품 맥락에 한정. 이전의 회색/노랑 배너 반복 제거.
- Figma 특정 화면과의 픽셀 일치가 아닌 회사 홈페이지 신규 레이아웃.
