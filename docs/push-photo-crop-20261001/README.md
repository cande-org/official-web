# 푸시 첨부 사진 정사각형 자르기

2026-10-01 사용자 요청: 사진 선택 시 정사각형 영역을 직접 선택해 첨부.

- JPG/PNG/WEBP 선택 후 모달에서 정사각형 결과를 미리 확인한다.
- 마우스/터치 드래그, 확대, 가로/세로 위치 슬라이더, 방향키, 가운데 초기화 제공.
- 확인한 영역만 최대 1024×1024 JPEG로 변환한다. 투명 영역은 흰색이며 원본 파일명/메타데이터는 업로드하지 않는다.
- '자르기 수정'은 원본을 사용한다. 취소/Escape/닫기는 기존 확정 사진을 유지한다.
- 파일 교체/제거/새 푸시/로그아웃 시 편집 상태를 정리하고 ImageBitmap을 해제한다.
- 업로드는 기존 발송 요청 시점에만 수행하며 재시도는 같은 이미지 ID를 유지한다.
- 기존 이미지 이력을 다시 자르거나 수정하지 않는다. iOS/Android의 알림 표시 방식은 OS에 따라 다를 수 있다.

검증: `npm run check`, `npm test` (4개), `npm run build`, 실제 Chrome `tests/push-browser.mjs`, `tests/admin-image-csp-browser.mjs` 통과.
브라우저에서 가로 PNG·세로 JPEG·정사각형 투명 WEBP의 크기/선택 영역 픽셀, 확대/드래그/재편집/취소, 업로드 재시도, 390px 가로 넘침을 확인했다. 390px 편집창 캡처를 육안 확인했다. 테스트 브라우저는 종료했다. 운영 알림 추가 발송은 하지 않았다.
