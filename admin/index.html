활동 당시 로그인 상태를 기준으로 조회합니다. 비로그인은 게스트 계정이며, 전체에서는 같은 이용자를 한 명으로 계산합니다.

기간별 상세 지표
집계 기준

재방문·리텐션은 인증된 서버 활동 기준입니다. 앱 시작 시 이용권 조회, 방 생성, 사용자 메시지 접수를 활동으로 봅니다. 서버에 접속하지 않은 화면 탐색·오프라인 실행은 포함하지 않습니다. 같은 날 여러 번 활동해도 한 명이며 재방문은 선택한 로그인 상태에서 처음 활동한 날보다 나중 날짜에 같은 상태로 다시 활동한 사람입니다. 누적 가입·이번 주 가입·현재 회원과 처리 대기 수는 필터와 무관한 전체 운영 현황입니다.

로그인 필터는 가입일, 비로그인 필터는 게스트 시작일을 D0으로 삼습니다. D1·D7·D30은 해당 한국 날짜에 선택한 상태로 다시 활동한 이용자 / 그 날짜가 끝난 이용자입니다. 전체는 가입 코호트 기준입니다. 7일 전환은 가입 후 168시간이 지난 회원 중 가입 시각부터 168시간 이내 채팅 접수·실제 결제를 한 비율입니다. 선택 종료일 이후 결과는 사용하지 않고, 아직 관찰 중인 사람과 신규 수집 이전 가입자는 분모에서 제외합니다. 주·월도 일별 비율을 평균내지 않고 사람 수로 다시 계산합니다.

실제 구매는 서버가 검증한 PRODUCTION·유료 거래이며 갱신 포함, 재전송·Sandbox·무료 체험·목결제는 제외합니다. 이후 환불되어도 이미 발생한 결제 경험은 유지하므로 순매출 지표가 아닙니다. 광고 시청은 서버 보상 검증 완료 건수로, 노출·중도 종료·보상 검증 실패는 포함하지 않습니다. 결제·광고가 비활성인 베타의 결과를 실제 전환 실패로 해석하지 마세요.

SNS 가입 완료를 회원가입으로 집계합니다. 게스트가 처음 SNS를 연결하면 가입 1회로 기록하며 재로그인은 늘어나지 않습니다. 게스트 시작은 별도 표시합니다. 누적 가입에는 이후 탈퇴한 회원도 포함되며 현재 회원은 따로 표시합니다. 관리자 계정은 수집에서 제외합니다.

채팅방 생성 유저와 메시지 전송 유저는 선택한 기간마다 중복을 제거합니다. 같은 유저가 게스트와 회원으로 모두 채팅하면 각 분류에 포함될 수 있으며, 전체 채팅 유저는 한 명으로 계산합니다. 전송은 서버가 접수한 사용자 턴이며 자동 인사와 목모드는 제외합니다. 성공·실패는 결과가 확정된 날짜 기준이므로 같은 날짜의 전송과 합계가 다를 수 있습니다.

가입은 기존 계정의 확인 가능한 가입 시각으로 초기화했습니다. 채팅방·전송 지표는 수집 시작 이후부터 제공하며 이전 기간의 0은 과거 활동이 없었다는 뜻이 아닙니다. 기간 가장자리의 주·월은 선택한 날짜 범위만 포함합니다.

푸시 발송 이력

알림을 허용한 기기로 발송한 이력입니다. 제목을 누르면 본문, 예약 정보, 클릭 집계를 볼 수 있습니다. 최근 100건을 표시합니다.

클릭률은 집계 지원 앱에 발송 성공한 기기 중 알림을 누른 비율입니다. 기기별 1회만 세며, 이전 앱과 이전 발송 이력은 집계에서 제외합니다.
